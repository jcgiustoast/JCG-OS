### Notes-app list
- **What it is:** A short list in the look of an iPhone Notes screenshot: 5–10 lines on one thing, on the cycle's topic. Juan writes the words; Claude puts them into the notes template in the Contenido Figma file (page "Notes list template", tall X version + 4:5 version). Max's subject-lines list in his notes app got 350 saves. Juan picks each week whether he writes any (0–3).
- **Platforms:** X image (Mon, Wed, Fri at 01:00 Madrid the night after, which is 19:00 in New York). One a week is expanded into next Monday's checklist carousel; Friday's X images are that Monday carousel (cover + 3 best). One can be the LinkedIn image on a non-Resource Friday. On Instagram a notes screenshot sits in a 4:5 frame. Notion: Format = Notes list.
- **Extra check:** Nothing that describes how Juan's employer does it. No numbers from work.
- **Time:** About 20 minutes each (3 a week, ~1 hour).

### Brand verdict (single image)
- **What it is:** A screenshot of a real brand's page (product page, subscribe box, checkout, cart drawer, upsell) plus Juan's 1–2 line verdict, framed "10/10, steal this". Claude finds the pages in Chrome and takes the screenshots. Juan writes the verdict.
- **Platforms:** X image (weekdays 19:55 Madrid, on the days Juan picks; the other weekdays get a framework infographic), Instagram story, the best one as a LinkedIn image (Friday, non-Resource weeks). They all go into Wednesday's "Pages worth stealing" carousel, so Juan writes them on Sunday. Notion: Format = Brand verdict (a one-page teardown video uses it too).
- **Extra check:** Same brand screen as rankings: public brands outside men's health, screenshot from the live site. Never a client's page or Mars Men's.
- **Time:** About 6 minutes each (0–5 a week, Juan picks).

### Framework carousel
- **What it is:** One framework as a carousel, built in Figma with `/figma-post`. Starts from the six framework ideas in Notion (growth formula, metric tree, 11 profitability levers, 7 habits, ICE, LTV). In video weeks it comes from Tuesday's video. Juan gives the framework or corrects Claude's draft from the source article.
- **Platforms:** LinkedIn and Instagram Thursday, X next Monday as images (cover + 3 best). Becomes one summary infographic. 1080×1350.
- **Extra check:** On the cycle's topic. Last slide: "Comment [KEYWORD]" for the topic's resource.
- **Time:** About 1 hour.

### Infographic
- **What it is:** One designed image, built with `/figma-post`. Either the summary of the week's framework carousel, the image for an idea long post, or one part of a framework for the weekday X post (on the days without a verdict).
- **Platforms:** Instagram (Friday), X (Monday, with the carousel images; weekdays 19:55 for framework parts), LinkedIn (Tuesday's idea post). 1080×1350 (4:5), the tallest the scheduler takes on Instagram.
- **Extra check:** Same as the piece it comes from.
- **Time:** Claude makes it; Juan only approves it.

### Weekly content v2 chains (added 2026-11-26)
