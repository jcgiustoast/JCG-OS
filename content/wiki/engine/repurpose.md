# Repurposing Chain

> One idea enters. N platform-native pieces come out. Each one THINKS about the topic differently — this is NOT reformatting. If someone followed Juan on all three platforms, they should not be annoyed seeing the same idea reused.

## Why Juan's Chain is Long-Form-First (Not X-First)

The article recommends writing X first because brevity forces clarity. For Juan, that's wrong. His signature move is the **Economics Reveal** — math that needs room to breathe before it can be compressed. Starting on Twitter strips the proof; starting on blog or LinkedIn builds it, then Twitter becomes the compression.

**Exception:** Hot takes, Contrarian Premises, and standalone observations can originate on Twitter and expand outward.

## The Two Chain Paths

### Path A: Framework-Heavy Topic (default)

Use when the topic involves a framework, formula, or Economics Reveal.

**Step 1: [[blog]] (Seed)**
Write the full framework with math, subheadings, inline formulas, comparison tables. 1,500-3,000 words.

**Step 2: [[linkedin]] (Narrative)**
Extract one framework or one Economics Reveal. Add personal narrative framing ("3 months ago I was diagnosing a brand that..."). 1,300-2,000 chars. Different angle: the story, not the system.

**Step 3: [[twitter]] (Compression)**
Distill the core framework into a 5-8 tweet thread. Or extract one contrarian claim into a single tweet. Different angle: the punchline, not the proof.

### Path B: Hot-Take Topic

Use when the topic is a single contrarian insight or observation.

**Step 1: [[twitter]] (Seed)**
Write the contrarian single or short thread. Force brevity.

**Step 2: [[linkedin]] (Expand)**
Add narrative context, personal framing, and the Economics Reveal behind the take. Different angle: why it matters, not just what's wrong.

**Step 3: [[blog]] (Deepen — optional)**
Only if the take earns an audience. Turn into a full framework piece. Different angle: the full system replacing what's broken.

## Five-Platform Chains (added 2026-11-25)

Paths A and B still decide where a written idea starts. These four chains cover the formats that came with Instagram, TikTok and YouTube. Every version links back to its source piece in Notion, so when the source changes the weekly plan lists the siblings to re-check.

### Chain C: One vertical video → three platforms
- **Source:** One 45–75 second video filmed at the desk (ranking, pages worth stealing, cut-down from a YouTube long).
- **Goes to:** Instagram Reel, TikTok, YouTube Short. Same file.
- **What changes:** Caption and hashtags only. Instagram caption ends with the keyword when it's a guide week. TikTok caption stays short. Short title fits about 40 characters.
- **Why the same file is fine here:** The litmus test is about people who follow on several platforms. Short-video audiences barely overlap, and Max's evidence shows the same file doing well on each.

### Chain D: One carousel → three platforms
- **Source:** One carousel built from the template (checklist, pages worth stealing, ranking in slides).
- **Goes to:** LinkedIn (PDF document), Instagram carousel, X.
- **What changes:** LinkedIn gets a full written post above the PDF. Instagram gets a short caption and the keyword. X takes at most 4 images, so X gets the cover plus the 3 strongest slides, or the list as plain text.
- **Order:** LinkedIn first (Mon/Wed), Instagram the next morning (Tue/Thu).

### Chain E: One YouTube long video → many pieces
- **Source:** A brand study or yearly tutorial.
- **Goes to:** 3–5 cut-downs (each becomes a Chain C video), one LinkedIn free-guide post built on it, one X list post of the main findings.
- **What changes:** Each cut-down is one finding with its own hook. Not a trailer for the long video.
- **Timing:** Cut-downs spread over the 2 weeks after the long video.

### Chain F: X winners come back
- **Source:** X posts that did well (rule of thumb: top 10% by likes + bookmarks).
- **Goes to:** The same post, re-posted about 6 months later. Strong ones also become a LinkedIn post or a carousel.
- **Status:** Automatic re-posting waits until it's confirmed the scheduler can do it. Until then, the weekly review lists posts that are old enough to come back.

### Threads
Every X post is copied to Threads by the scheduler. No separate writing.

### Weekly batch (five-platform version)
1. Sunday: weekly plan fills every slot and lists the sibling versions.
2. One writing block: LinkedIn long posts, X posts, carousel text.
3. One filming block: all vertical videos of the week.
4. Review all versions together. Check each against the limits table in [[content-types]] before marking it Ready.
5. Schedule every evening slot. Nothing after 19:00 Madrid is posted by hand.

## What Actually Changes Between Platforms

| Element | How It Adapts |
|---------|---------------|
| Angle | Different entry point into the same topic (system vs story vs punchline) |
| Hook | Rewritten per [[hooks]] and [[platform-tone]] |
| Tone | Rigorous (blog) → narrative (LinkedIn) → compressed (Twitter) |
| Format | Long-form → standard post → thread/single |
| Length | 2,000 words → 1,500 chars → 280 chars |
| Depth | Full proof → one proof point → punchline |

## The Litmus Test

Before publishing, ask:
- **If someone followed me on all three platforms, would they be annoyed seeing the same thing everywhere?**
- If YES → you're reformatting. Go back and find a different angle.
- If NO → you've made 3 unique pieces from one idea. Ship.

## Batch Workflow

1. Pick 1 framework-heavy topic + 1 hot-take topic per week
2. Run Path A for the first, Path B for the second
3. Write all platform versions in one session — don't spread across days
4. Review all outputs together before publishing any
5. Schedule using cadence from [[content-strategy]]
